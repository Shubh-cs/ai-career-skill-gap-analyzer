# 🚀 AI Career Skill Gap Analyzer

An AI-powered web app that analyzes a student’s resume against role-specific skill requirements and generates a personalized **90-day learning roadmap**.

Built with **Python + Streamlit**.

---

## 🚀 Live Demo

Try the app here:

👉 https://ai-career-skill-gap-analyzer.streamlit.app/

---

## 📌 Problem

Most students (especially early-career learners) know the role they want:

- Backend Developer  
- Data Analyst  
- LLM Engineer  
- Cybersecurity Engineer  

But they don’t know:

- What skills they are missing  
- What they should learn next  
- How to follow a structured roadmap  

So they end up following random courses, social media advice, and scattered roadmaps without clarity.

---

## ✅ Solution

This app helps students by:

1. Selecting a target career role  
2. Pasting their resume / skills  
3. Automatically identifying:

- ✅ Skills Found  
- ❌ Skills Missing  

4. Generating a structured:

- Days 1–30 (Foundation)
- Days 31–60 (Application)
- Days 61–90 (Job Ready)

---

## ✨ Features

- Role-based skill gap detection  
- Resume text input support  
- Missing skills highlighting  
- Personalized 90-day roadmap generation  
- Simple, clean Streamlit UI  
- Deployed live on Streamlit Cloud

## ⚙️ Installation & Run Locally

```bash
# Clone the repository
git clone https://github.com/Shubh-cs/ai-career-skill-gap-analyzer.git

# Move into the project folder
cd ai-career-skill-gap-analyzer

# Install required dependencies
pip install -r requirements.txt

# Run the Streamlit app
streamlit run app.py

#Then open:
http://localhost:8501
```
